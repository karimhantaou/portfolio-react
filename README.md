## 🚀 Fonctionnalités

- Développé avec React.js

- Responsive design

- Navigation fluide en Single Page Application (SPA)

- Mise en avant de projets et compétences techniques

- Hébergement en ligne pour un accès public

## ⚙️ Installation

1. [Télécharger Node.js](https://nodejs.org)

2. Clonez le repo :

    ```bash
    git clone https://github.com/karimhantaou/portfolio-react.git
    cd portfolio-react
    ```

3. Installez les dépendences

    ```bash
    npm install
    ```

## ▶️ Utilisation

Pour lancer le serveur de développement :
```bash
npm start
```

Pour créer un build optimisé du projet :
```bash
npm run build
```
